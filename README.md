# Library Management System

## Project Overview

This project is being developed as part of the Software Engineering Lab.

The goal is to build a simple web-based application for organizing library books and tracking basic borrowing activities.

## Planned Features

- Browse and search the book catalogue
- Add new books
- Record borrowing and returns
- View basic library statistics

## Technologies

- HTML
- CSS
- JavaScript
- Git and GitHub

## Development

The application will be developed incrementally, with changes tracked using Git.
